# Design

Preserve the existing dashboard's navy masthead and mint, orange, blue and yellow data accents. The trends page uses a warm light background and dark labels. This revision corrects wrapping and chart legibility, not the site's visual identity.

Archivo is the existing display font. Use system sans-serif for text and chart labels. Long statistics use a smaller non-wrapping font than single counts. Use two metric columns on narrow screens. Large trend charts scroll horizontally on phones rather than reducing labels below readable size. Keep chart legends in normal document flow.

The report uses black Georgia headings, Arial body text and pale blue table headings with bold black text. Captions are short; substantive caveats belong in the text. No running page headers or footers.
